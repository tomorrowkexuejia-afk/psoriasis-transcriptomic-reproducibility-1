## 为什么由上一审阅稿的31项变成33项

这次获得并直接阅读了TLN1/GYS1原论文的完整补充图，原来因“补充来源待核”而暂时整体排除的两项可以恢复。GSE121212仍因原论文使用过而被排除，每项使用其余六个开发队列。新增阅读也发现TLN1正文上调与补充图显示模式不一致，论文据此将其解释为来源叙述不一致的案例。

INSIG1额外验证队列仍未完整核清，没有为了扩大分母而强行纳入。PANoptosis五项在删除来源已使用的队列后均仅剩一个开发队列，不满足合并规则。完整原始39项结果继续在补充文件中保留。

## 一键重跑

建议使用已验证的Python 3.12。分析依赖列在requirements.txt。

```bash
python code/run_pipeline.py
```

脚本先验证输入哈希，再生成历史数值复算、来源修订后的两套分析、留出结果、敏感性表和五张科学图，并执行回归检查。目录名为`source_adjudicated_subset_*`的33项结果对应正文。

`confirmed_use_corrections_*`为34项暂定敏感性版本，额外包含来源仍待核的INSIG1，不是正文主结果。`results/`中的原39项网格用于历史数值对照，不能替代来源核定后的正文分析集。

```bash
python code/verify_release.py
```

可单独执行针对已知计算和来源问题的回归检查。
