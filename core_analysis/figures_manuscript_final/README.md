## Why this directory exists

The figures in `../figures/` were generated by `build_corrected_outputs.py` at the time of the
Zenodo v1.0.0 deposit. Three of them still carry the earlier wording:

| Archived file | In-figure wording | Final manuscript wording |
|---|---|---|
| `../figures/Figure1_Provenance_Audit_Flow.*` | `Candidate inventory`, `Confirmed source reuse` | `Archived source inventory`, `17 source-used cohort tests excluded`, `5 PANoptosis claims excluded` |
| `../figures/Figure3_Adjudicated_Interval_Sensitivity.*` (= manuscript Figure S2) | `Dev. normal`, `Dev. mHK`, `+ holdout normal` | `Development normal`, `Development mHK`, `Updated normal (+ separate cohort)` |
| `../figures/Figure4_TLN1_GYS1_Provenance_Qualified.*` (= manuscript Figure S3) | `GSE295540 holdout`, `separate holdout` | `GSE295540 separate cohort`, `separate cohort` |

The **numbers are identical** in both versions. For the source-adjudicated 33-claim set the Figure
S2 bars are: development normal CI 32 positive / 1 negative, development mHK 30 positive / 3
crossing, updated normal CI 32 / 1, updated mHK 32 / 1; and the prediction-interval panel 30 / 3,
16 / 17, 30 / 3 and 21 / 12. Only the in-figure wording and the Figure 1 layout differ. The final
manuscript uses "separate RNA-seq cohort" throughout (`holdout` does not appear in the text), so
the files in this directory are the authoritative versions for the published article.

Per the archive's own versioning rule, the deposited v1.0.0 files in `../figures/` were **not**
modified. This directory is additive and does not change any previously released file.
