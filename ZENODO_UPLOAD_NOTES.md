# Suggested Zenodo metadata

**Resource type:** Dataset (a combined reproducibility archive containing processed data, code and outputs)

**Suggested title:**
Reproducibility archive for dataset provenance, sample overlap and direction preservation in cross-cohort reproducibility of transcriptomic biomarker claims

**Suggested version:** 1.0

**Suggested description:**
This repository contains processed analysis inputs, claim-level eligibility decisions, cross-accession sample-overlap exclusions, reproducible analysis code, numerical outputs, sensitivity analyses, paired audit-impact analyses, and publication figures supporting an empirical methodological study of transcriptomic biomarker reproducibility in psoriasis. The final source-adjudicated development analysis contains 33 paper-gene claims representing 32 genes and 176 eligible cohort contributions. The archive also contains a separate small RNA-seq boundary cohort and complete provenance/audit materials.
